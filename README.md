## Current Research

### AxiomCervix-Q

A controlled research project exploring **morphology-aware hybrid quantum-classical learning for candidate-level cervical cytology evidence**.

The project is built around source-aware evaluation, reproducibility, external validation, localization analysis, and careful comparison between classical and quantum-enhanced approaches. Scientific results are treated as evidence to be preserved rather than optimized for a preferred conclusion.

`Research status: private / controlled review`
